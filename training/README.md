# Training

Two files matter:

| File | Role |
|---|---|
| `airspace_sentinel_train.py` | **source of truth** — jupytext `# %%` cells, runs headless or as a notebook |
| `airspace-sentinel-train.ipynb` | generated by `node build_notebook.mjs` — this is what you open on Kaggle |

Never edit the `.ipynb` by hand; edit the `.py` and regenerate (keeps diffs reviewable and lets CI lint the pipeline).

## Run it

1. Kaggle → **Create → Notebook** → upload `airspace-sentinel-train.ipynb`
2. Accelerator: **GPU T4 x1**, Internet: **on**
3. Add datasets (or let `kagglehub` fetch them — needs Internet on):
   - `dasmehdixtr/drone-dataset-uav`
   - `muki2003/yolo-drone-detection-dataset`
   - `muhammadsaoodsarwar/drone-vs-bird`
4. **Run All**. Expect ~2 h.

## The gate (cell 6)

Before the full run the notebook trains 1 epoch on 200 images, exports ONNX, and
executes the graph through ONNX Runtime. If that cell fails, **stop** — the export
path is the unproven link, and the documented fallback is switching the detector
to mmdetection RT-DETR (Apache-2.0, supported ONNX deploy path).

This exists because discovering an export problem after a 2-hour training run is
the most expensive way to learn it.

## Outputs (in `/kaggle/working`)

| File | Use |
|---|---|
| `weights/sentinel-det-v1.onnx` | FP32 graph — drop-in for `apps/api` |
| `weights/sentinel-det-v1-int8.onnx` | INT8, ~4x smaller; ship only if ΔmAP < 2 pts |
| `metrics.json` | mAP50, AP-small, bird FPR, latency — copied into `benchmarks/` |
| `model_card.md` | generated card; publish beside the demo |

## Publish weights for the API

Upload `sentinel-det-v1.onnx` (+ int8, metrics, card) as a **Kaggle Dataset**,
then reference it by slug. The repo never commits binaries — `models/` is
gitignored and the API verifies `sha256` from `metrics.json` at load time.

## What the metrics must show

| Claim | Metric | Acceptable for a public demo |
|---|---|---|
| Finds UAVs | mAP50 up to 0.55 (liftoff is >0.60) | |
| Finds *small* UAVs | AP-small | report it separately, never hide it behind mAP |
| Does not fire on birds | bird FPR | < 15%, or add the CLIP re-scoring stage |
| Runs without GPU | p95 latency @ 640² | < 1500 ms |
